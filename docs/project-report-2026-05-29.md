## 一、产品定位与核心价值

### 1.1 一句话定位

**EHM AI 工作台是面向工业设备管理领域的 AI 超级智能体平台。**

> 让设备运维人员通过自然语言对话，完成从数据查询、趋势分析、故障诊断到报告生成的全链路工作，将工业数据分析门槛从"需要数据科学家"降低到"会打字就能用"。

### 1.2 业务价值速览

| 价值维度 | 量化收益 | 实现路径 |
|---------|---------|---------|
| **效率提升** | 报告生成时间从 2-4 小时 → 5-15 分钟 | DSL 模板 + 自动化数据管道 |
| **知识沉淀** | 专家经验从"人脑"→"可复用 Agent" | 44 个工业技能包 + 16 个内置 Agent |
| **闭环管理** | 故障发现→整改→验证全链路可追溯 | 闭环工单系统 + 6 种来源自动建单 |
| **成本管控** | Token 用量实时追踪，日/月预算控制 | 费用管控系统 + 80% 阈值告警 |
| **多租户扩展** | 一套平台服务多个工厂/事业部 | 三级智能体发现 + 租户隔离 |

### 1.3 关键业务指标

- **平台规模**：1329 个源文件、431 个测试文件、45 个 API 路由
- **功能完整性**：16 个内置 Agent、8 套报告模板、44 个工业技能、7 路 IM 接入
- **技术成熟度**：18 层中间件链、3 层记忆系统、Protocol 适配器框架
- **部署就绪度**：Docker Compose 单机部署、K8s 沙箱隔离、Nacos 服务发现

## 二、用户画像与典型场景

### 2.1 核心用户角色

| 角色 | 核心痛点 | EHM AI 工作台解决方案 |
|------|---------|---------------------|
| **设备运维工程师** | 重复性工作多（日报/周报手动编写）、数据分析门槛高 | 对话式生成报告（5 分钟完成 2 小时工作）、智能诊断建议 |
| **可靠性工程师** | 需要专业数据分析能力、历史数据分散 | 内置趋势分析 Agent、KPI 自动计算、异常预警 |
| **班组长/运维主管** | 整改进度难追踪、责任不清 | 闭环工单系统、SLA 自动计时、状态可视化 |
| **工厂管理者** | 缺乏直观的数据汇总、报告滞后 | 日报/周报/月报自动生成、关键指标高亮 |
| **租户管理员** | 多工厂管理复杂、成本不可控 | 三级智能体管控、Token 预算告警、审计日志 |

### 2.2 典型使用场景

#### 场景 1：设备日报生成（效率提升 95%）

```text
用户："帮我出一份昨天的设备日报，重点关注 A 区机泵"
  ↓
Agent 调用 ai-report--daily Agent
  ↓
弹出 3 步表单：① 日期范围 → ② 设备选择 → ③ KPI 勾选
  ↓
自动从 InS 拉取数据、计算 KPI、生成 ECharts 图表
  ↓
输出 Markdown 报告 + PDF（可选），支持下载/分享
  ↓
总耗时：5-15 分钟（传统方式：2-4 小时）
```

#### 场景 2：故障诊断与闭环（从发现到整改全链路）

```text
用户："诊断一下 B-203 压缩机的振动异常"
  ↓
fault-diagnosis--reciprocating Agent 分析频谱数据
  ↓
输出诊断结论（严重等级：high）+ 建议措施
  ↓
自动创建闭环工单（source_type=diagnosis）
  ↓
派单 → 处置 → 验证 → 关闭（全程状态追踪）
  ↓
下周周报自动包含该工单的整改进展
```

#### 场景 3：知识库问答（经验沉淀与复用）

```text
新员工："离心泵机械密封泄漏的常见原因有哪些？"
  ↓
RAG 检索企业知识库（历史故障案例、维修手册）
  ↓
Agent 结合检索结果生成结构化回答
  ↓
附带相关案例链接、参考文档、处理建议
  ↓
新员工 10 分钟掌握老师傅 10 年经验
```

#### 场景 4：自定义报告模板（领域专家赋能）

```text
可靠性工程师："我要创建一个'旋转设备振动趋势'报告模板"
  ↓
使用可视化编辑器拖拽表单步骤、数据步骤、章节
  ↓
DSL 自动生成，实时校验，发布到模板市场
  ↓
其他工程师安装模板，一键复用
  ↓
形成"专家生产模板 → 全员复用 → 反馈改进"飞轮
```

## 三、产品架构与能力全景

### 3.1 三层产品结构

EHM AI 工作台采用**三层产品结构**，清晰划分平台能力、企业管控和行业方案：

```text
┌─────────────────────────────────────────────────────────────┐
│  Industry Solution Layer（行业方案层）                       │
│  ├── 行业 Skill（44 个工业技能包）                           │
│  ├── 行业报告模板（8 套内置模板）                            │
│  ├── 行业 Agent（16 个内置 Agent）                           │
│  └── 行业数据集成（InS/DCS/MES 适配器，2k/6k/8k/9k 四系列）  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Enterprise Control Plane（企业管控面）                      │
│  ├── 多租户隔离（上下文解析、存储路径、能力作用域）          │
│  ├── Agent/Skill 管控（租户级创建、启用/禁用、MCP 配置）     │
│  ├── 认证集成（JWT/API Key、InS Base、权限中间件）           │
│  ├── 报告管控（可见性管理、运行历史）                        │
│  └── 连接器管理（租户级 HTTP 连接器、外部 API）              │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  Core Platform（通用平台层）                                 │
│  ├── Agent 编排引擎（生命周期、多 Agent 协作、工具调用）     │
│  ├── AI 基础设施（LLM 接入、RAG 管道、知识库、内容安全）     │
│  ├── 报告 DSL 引擎（声明式模板、版本管理、渲染、脚本执行）   │
│  ├── 闭环工单引擎（通用状态机、审计事件）                    │
│  └── 可观测性（追踪、成本核算、Token 统计）                  │
└─────────────────────────────────────────────────────────────┘
```

**三层边界原则**：

- **Core Platform**：提供能力和 API，不关心租户如何启用/禁用
- **Enterprise Control**：配置层面对 Core 进行管控，不修改 Core 代码
- **Industry Solution**：依赖 Core 框架，通过 Enterprise 被租户采纳

## 五、业务价值与 ROI 分析

### 5.1 效率提升价值

| 场景 | 传统方式耗时 | EHM AI 工作台耗时 | 效率提升 | 年化节省（按 200 工作日计） |
| --- | --- | --- | --- | --- |
| 设备日报 | 2-4 小时 | 5-15 分钟 | **95%** | 380-780 小时/人 |
| 故障诊断 | 1-2 天 | 30-60 分钟 | **90%** | 180-380 小时/人 |
| 趋势分析 | 4-8 小时 | 15-30 分钟 | **93%** | 770-1570 小时/人 |
| 闭环跟踪 | 手工 Excel 管理 | 自动状态机 | **80%** | 难以量化，但可追溯性提升 100% |

### 5.2 知识沉淀价值

- **经验复用**：44 个工业技能包 = 44 位"虚拟专家"，每位封装了特定领域的最佳实践
- **模板复用**：8 套内置报告模板 + Marketplace 生态，新工厂 1 天内可完成报告体系搭建
- **培训成本**：新员工通过知识库问答 + 内置 Agent，10 分钟掌握老师傅 10 年经验

### 5.3 成本管控价值

- **Token 预算**：日限 $50、月限 $1000（可配置），80% 阈值告警，超限自动 block
- **多租户隔离**：一套平台服务多个工厂/事业部，边际成本递减
- **私有化部署**：数据不出厂，满足国企/央企合规要求，避免公有云 SaaS 的长期订阅成本

```text
领域专家（生产者） → 创建并发布模板 → 普通用户（消费者）安装使用
       ↑                                          ↓
       └──── 反馈改进建议 ←──── 使用数据 + 评价 ←──┘
```

**飞轮阶段**：

| 阶段 | 目标 | 关键指标 |
| --- | --- | --- |
| **冷启动** | 内置 8 套高质量模板，降低使用门槛 | 模板安装率 > 60% |
| **增长期** | 激励领域专家发布模板，丰富品类 | 月新增模板 > 10，安装量 > 100 |
| **成熟期** | 形成行业标准，模板成为"工业报告规范" | 跨租户复用率 > 40%，付费模板占比 > 20% |

### 6.1 竞品对比矩阵
