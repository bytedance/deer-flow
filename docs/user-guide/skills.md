## 1. 什么是 Agent Skill

Agent Skill（智能技能）是 EHM AI 工作台的核心能力单元。每个 Skill 封装了一种专业分析能力——从设备振动诊断到趋势报告生成，再到通用数据查询。

当你在工作台输入一段自然语言请求时，系统会自动选择合适的 Skill 来完成任务。

---

## 2. 技能分层：工业智能 vs 基础工具

EHM AI 工作台的技能分为两个层级（Tier）：

### 2.1 工业智能（Core Industrial）

**定位**：面向工业设备管理场景的专业技能，是平台的核心价值所在。

**典型技能**：

| 技能名称 | 用途 |
|----------|------|
| `vibration-fault-diagnosis` | 振动数据分析与故障诊断，支持 ISO 10816 标准评级 |
| `ins-device-analysis` | 设备运行状态综合分析 |
| `rotating-diagnosis-*` | 旋转机械（泵、压缩机、风机等）专项诊断 |
| `monitoring-*` | 设备监测数据分析与预警 |
| `trend-report` | 设备运行趋势报告生成 |
| `daily-equipment` | 设备日报自动生成 |

**特点**：
- 深度融合工业领域知识（ISO 标准、设备类型、故障模式）
- 输出带工业监控风格图表（正常=绿、预警=黄、报警=红）
- 支持设备位号、测点、工况参数等专业输入

### 2.2 基础工具（Foundation）

**定位**：通用分析能力，为工业场景提供底层支撑，也可独立使用。

**典型技能**：

| 技能名称 | 用途 |
|----------|------|
| `data-analysis` | 通用数据查询与聚合分析 |
| `deep-research` | 多源信息检索与综合研究 |
| `image-generation` | 图片生成（流程图、示意图等） |

**特点**：
- 不依赖特定工业领域知识
- 可被工业智能技能调用作为子步骤
- 适合探索性、非结构化的分析任务

## 3. 使用技能

### 3.1 自动选择（推荐）

大多数情况下，你不需要手动选择技能。直接在工作台输入框描述你的需求：

```
帮我分析 P-101A 泵最近一周的振动趋势
```

系统会自动识别意图，调用 `vibration-fault-diagnosis` 或 `trend-report` 技能。

### 3.2 手动启用/禁用技能

进入 **设置 → 技能** 页面：

1. 在技能列表中，使用开关启用或禁用特定技能。
2. 使用顶部的 **Industrial / Foundation** 标签页筛选技能。
3. 使用搜索框按名称或描述查找技能。

**建议**：保持工业智能技能全部启用，按需禁用不需要的基础工具。

## 4. 技能选择器

当你在新对话中点击技能选择器时，会看到：

- **工业智能 Tab**（默认）：展示所有 `core-industrial` 技能，按使用频率排序
- **基础工具 Tab**：折叠展示 `foundation` 技能

这种设计确保工业场景的专业技能始终在最显眼的位置。

---

## 5. 管理员：技能层级管理

租户管理员可以在 **管理后台 → 技能** 页面进行层级管理：

1. **查看层级**：技能表格的「Tier」列显示每个技能的当前层级。
2. **修改单个技能**：点击 Tier 下拉框，选择 `Core Industrial` 或 `Foundation`。
3. **批量修改**：勾选多个技能，点击「Set Core Industrial」或「Set Foundation」批量更新。
4. **按层级过滤**：使用顶部筛选器只看某一层的技能。

**什么时候需要调整层级？**

- 当你创建了自定义技能并希望它出现在工业智能 Tab 时，将其设为 `Core Industrial`。
- 当某个工业技能不再适用你的业务场景时，可以降级为 `Foundation`（不会被删除，只是不再优先展示）。

## 6. 工业场景操作示例

### 示例 1：设备故障诊断

```
用户：P-203B 压缩机振动值超标，帮我做个诊断
系统：调用 vibration-fault-diagnosis 技能
      → 拉取最近 7 天振动数据
      → 按 ISO 10816 标准评级
      → 输出诊断报告 + 建议措施
      → 如果严重等级 ≥ high，自动创建闭环单
```

### 示例 2：设备趋势报告

```
用户：生成本月所有 A 类设备的运行趋势报告
系统：调用 trend-report 技能
      → 查询 A 类设备清单
      → 拉取本月运行数据
      → 生成含趋势图表的报告
      → 提供 Markdown 下载
```

### 示例 3：日报自动生成

```
用户：出一份今天的设备日报
系统：调用 daily-equipment 技能（报告模板平台 builtin）
      → 弹出表单：选择日期、设备范围、关注 KPI
      → 聚合当日运行数据
      → 生成日报 + 异常设备标记
```

## 7. 常见问题

**Q：为什么有些技能在「工业智能」Tab 看不到？**
A：只有层级为 `core-industrial` 的技能会出现在工业智能 Tab。管理员可以在后台调整技能层级。

**Q：禁用了一个技能后还能恢复吗？**
A：可以。禁用只是关闭该技能的调用入口，不会删除数据。重新启用即可。

**Q：我可以创建自己的工业智能技能吗？**
A：可以。在设置页面点击「新建技能」，创建后让管理员将其层级设为 `Core Industrial` 即可。

**Q：基础工具技能有什么用？**
A：基础工具提供通用分析能力，工业智能技能在执行过程中可能会调用它们。例如，`vibration-fault-diagnosis` 在输出报告前可能调用 `data-analysis` 做数据聚合。
