# 角色路由、用户工作区与技能市场

## 目标

将 DeerFlow 调整为面向付费用户的多租户产品：未登录用户先登录，管理员仅使用运营后台，普通用户使用独立的对话与个人设置空间；管理员可发布技能，普通用户可从技能市场安装技能。

## 路由与可见性

- 根路径对未登录用户跳转 `/login`。
- 登录后按系统角色跳转：`admin` 跳转 `/workspace/admin`，普通用户跳转 `/workspace/chats/new`。
- 管理员的工作区隐藏对话、集成、记忆、工具、技能及其设置入口；服务端同样拒绝管理员访问普通用户工作区路由。
- 普通用户保留对话和设置中的集成、记忆、工具、技能功能。
- 设置中移除“关于”入口和相应内容展示。

## 租户隔离

- 一个注册用户就是一个独立租户。除平台计费策略、模型配置、用户管理和技能市场发行版外，所有用户可配置数据均为租户私有数据。
- 记忆、集成、工具、技能及后续新增的用户配置，其读写均以当前认证用户 ID 作为所有者条件；记忆不得以共享或全局方式回填给其他用户。
- 任何现有全局数据在读取时不得泄露给其他普通用户；对需要持久化的个人配置补充 `user_id` 归属字段与服务端校验。
- 每一个用户侧接口都必须从认证会话取得用户 ID，不接受客户端传入的租户 ID 作为授权依据。
- 管理员发布的市场技能是公共只读发行版，不属于任何普通用户的个人技能空间。

## 技能市场

- 管理员在运营后台新增“技能市场管理”，可创建、编辑、发布、下架市场技能。
- 每个市场发行版包括名称、简介、版本、技能内容或来源、发布状态和发布时间。
- 普通用户在“设置 → 技能 → 技能市场”浏览已发布技能，查看完整介绍和版本，并安装到自己的技能空间。
- 安装时创建用户自己的安装记录/副本，保留已安装版本；市场后续更新不会自动覆盖用户副本。
- 用户可在个人技能列表查看完整信息、展开长内容、主动更新到最新发行版或移除已安装技能。

## 错误与验证

- 非管理员调用市场管理接口返回 403；未发布或下架技能不可被普通用户安装。
- 管理员不可进入普通用户的对话和个人设置路由；普通用户不可访问运营后台。
- 重复安装相同市场技能应返回清晰状态或更新已有安装记录，而不是创建重复数据。
- 为角色路由、权限校验、技能市场发布/安装、个人技能完整展示增加后端与前端测试。
