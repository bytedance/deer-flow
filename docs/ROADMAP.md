# Roadmap & MVP

MVP goal (3 months): enable a creator to produce and export a short illustrated story with consistent characters.

MVP scope:
- Project & parametric character creation
- LLM-based outline -> scene list
- Template-based scene renderer (2 templates)
- Image generation with consistent character embedding
- Outfit selection (10 outfits)
- Export: PDF + web preview

Quarterly roadmap (Year 1):
Q1 - MVP, closed alpha
Q2 - Pose engine, outfit parametrics, voice studio
Q3 - Marketplace & monetization, advanced moderation
Q4 - Enterprise features and on-prem inference
