## 一、工业设备管理的痛点与挑战

在工业企业的设备管理实践中，普遍存在以下痛点：

### 1.1 数据孤岛，分析困难

- 设备运行数据分散在 DCS、SCADA、MES、ERP 等多个系统中
- 工程师需要手动导出、整理、对比数据，耗时耗力
- 缺乏统一的数据视图，难以进行跨系统的综合分析

### 1.2 报告编制效率低

- 日报、周报、月报需要人工整理，重复性工作占用大量时间
- 报告格式不统一，质量参差不齐
- 趋势分析、故障诊断等专业报告依赖资深工程师，知识难以沉淀

### 1.3 故障诊断依赖经验

- 设备故障判断高度依赖老工程师的经验
- 新员工培养周期长，独立诊断能力不足
- 故障案例分散在个人笔记、邮件、微信群中，缺乏系统化沉淀

### 1.4 知识流失严重

- 资深工程师离职带走大量经验
- 设备维修记录、故障处理方案分散，难以检索复用
- 缺乏持续积累的企业设备管理知识库

## 三、产品核心能力

### 3.1 智能对话式分析

**场景示例**：工程师只需在对话框中输入自然语言问题，AI 即可自动完成数据分析并给出结论。

```
用户：帮我分析一下 3# 压缩机最近一个月的振动趋势，有没有异常？

AI 助手：
好的，我来分析 3# 压缩机（设备编号：COMP-003）最近 30 天的振动数据。

【数据概览】
- 时间范围：2026-04-26 至 2026-05-26
- 振动测点：驱动端水平、非驱动端水平、驱动端垂直
- 数据点数：2,160 个（每小时采样）

【趋势分析】
1. 驱动端水平振动：整体呈上升趋势，从 4.2mm/s 升至 5.8mm/s，
   增幅 38%，超过 ISO 10816-3 的"良好"阈值（4.5mm/s）
2. 非驱动端水平振动：稳定在 3.1-3.5mm/s 范围内，无明显异常
3. 驱动端垂直振动：5 月 12 日出现一次突增至 7.2mm/s，随后回落

【诊断建议】
⚠️ 驱动端水平振动持续升高，建议：
1. 检查联轴器对中情况
2. 检查地脚螺栓紧固状态
3. 安排频谱分析，排查是否存在不平衡或不对中故障

是否需要我生成一份详细的趋势分析报告？
```

**能力特点**：
- ✅ 自然语言交互，无需学习复杂查询语法
- ✅ 自动接入设备运行数据（支持多种工业数据源）
- ✅ 结合行业标准（ISO 10816、API 670 等）给出专业判断
- ✅ 支持多轮对话，逐步深入分析

### 3.4 RAG 知识库 — 企业设备知识资产沉淀

**知识库能力**：

- **文档入库**：支持 PDF、Word、Excel、PPT、Markdown 等格式

- **知识注入**：AI 对话时自动检索相关知识，注入上下文
- **多租户隔离**：每个企业/部门独立的知识空间
- **持续积累**：每次对话、每份报告都可以沉淀为知识

**典型应用**：

```
场景：新员工遇到不熟悉的设备故障

传统方式：
1. 翻阅设备手册（几百页）
2. 在微信群里问老同事
3. 搜索历史邮件找类似案例
4. 耗时 2-3 小时，可能还找不到答案

EHM AI 工作台方式：
1. 在对话框描述故障现象
2. AI 自动检索知识库中的相关案例、手册、标准
3. 结合当前设备数据给出诊断建议
4. 附上参考来源，可进一步查阅

```

### 场景二：故障诊断与处理

**用户角色**：设备工程师 + AI 助手

**对话示例**：

```
工程师：2# 离心泵今天振动突然增大，驱动端水平振动达到 7.5mm/s，
       帮我分析一下原因。

AI 助手：收到，我来分析 2# 离心泵（PUMP-002）的振动异常。

【数据采集】
正在获取最近 7 天的振动数据、工艺参数和维修记录...

【分析结果】
1. 振动特征：
   - 驱动端水平振动今日 06:00 开始急剧上升（从 4.2mm/s 升至 7.5mm/s）
   - 频谱显示 1X 转频分量显著增大（占通频的 85%）
   - 非驱动端振动无明显变化

2. 工艺参数关联：
   - 流量：稳定在 120 m³/h
   - 出口压力：稳定在 0.8 MPa
   - 电机电流：无明显波动

3. 知识库检索：
   找到 3 个相似案例（相似度 > 85%）

【初步诊断】
根据 1X 转频主导 + 工艺参数稳定 + 突发特征，初步判断：
⚠️ 转子不平衡（置信度 78%）

可能原因：
- 叶轮积垢或腐蚀导致质量分布不均
- 联轴器螺栓松动
- 轴承磨损导致间隙增大

【建议处理步骤】
1. 立即：降低负荷至 80%，持续监测振动变化
2. 24 小时内：安排停机检查
   - 检查联轴器螺栓紧固力矩
   - 检查叶轮表面状况
   - 测量轴承间隙
3. 如确认不平衡：安排动平衡校正

是否生成详细的故障诊断报告？

工程师：好的，生成报告。

AI 助手：报告已生成，包含：
✅ 振动数据趋势图
✅ 频谱分析图
✅ 诊断结论与处理建议
✅ 3 个相似案例参考
✅ 安全措施提示

报告已保存至"报告历史"，可导出 PDF 分享给相关人员。
```

**价值体现**：
- 🧠 AI 辅助诊断，降低对资深工程师的依赖
- ⚡ 诊断时间从数小时缩短到分钟级

## 十一、常见问题（FAQ）

**Q1：我们的数据很敏感，能否保证数据安全？**

A：EHM AI 工作台支持完全私有化部署，所有数据存储在企业内部，不出域。同时提供多租户隔离、访问控制、操作审计等安全机制。

**Q2：我们没有 GPU 服务器，能否使用？**

A：可以。可以选择调用云端大模型 API（如 OpenAI、Claude、通义千问等），无需本地 GPU。对于数据敏感场景，也支持部署轻量级开源模型（如 Qwen-7B、DeepSeek-7B），在普通服务器上即可运行。

**Q3：我们的设备数据存储在 DCS/MES 中，如何接入？**

A：EHM AI 工作台提供多种数据接入方式：
- HTTP API 连接器（适配 RESTful 接口）
- MCP（Model Context Protocol）工具扩展
- 自定义数据导入脚本
- 文件导入（CSV/Excel/JSON）

**Q4：能否与我们现有的 ERP/EAM 系统集成？**

A：可以。EHM AI 工作台提供标准 REST API，支持与企业现有系统集成。同时支持 Nacos 服务发现，可无缝对接 Java 微服务架构。

**Q5：报告格式能否自定义？**

A：可以。EHM AI 工作台提供报告模板平台，支持通过 YAML DSL 自定义报告结构、数据处理逻辑、展示样式。同时内置 8 个标准模板，可一键 Fork 修改。

**Q6：支持哪些语言？**

A：当前支持中文和英文双语界面。AI 对话支持多语言，可处理中英混排的设备数据和文档。
