# Product specification (summary)

CyliaTales is an AI-first storytelling studio with the following pillars:

1. Narrative Engine — LLM-driven plot, character, worldbuilding with long-term memory and branching.
2. Visual Studio — generative high-fidelity stills, pose control, parametric outfits, and short animations.
3. Creator Studio — scene editor, timeline, versioning, co-editing, and exports to multiple formats.
4. Marketplace — templates, outfit packs, voice packs, and licensing.
5. Platform — sandboxed tool execution, scalable model hosting, and enterprise features.

Key differentiators (top highlights):
- Super-Agent orchestration for long-horizon creative sessions
- Cross-modal consistency via canonical character embeddings
- High-fidelity outfit parametrics and 2D/3D export
- Studio-grade lighting, camera, and animation presets
- One-click book & asset export plus marketplace monetization

For the full feature list, templates and outfits, see docs/ROADMAP.md and docs/ISSUES.md
