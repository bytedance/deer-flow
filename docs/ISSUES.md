2. Backend: character registry schema & embedding storage (P0)

5. Frontend: Next.js app base + landing page (P0)
6. Frontend: editor shell skeleton (canvas + left assets rail + right properties) (P0)
7. Frontend: wire project creation flow to backend (P0)
8. Integration: basic LLM outline -> scene list flow using hosted LLM API (P0)
9. Integration: image generation pipeline using one SDXL endpoint, store assets to S3 (P0)
10. Export: PDF generator for assembled scenes (P1)
11. Templates: create 2 starter templates (Children, Cinematic) with presets (P1)
12. Outfits: implement outfit metadata model and 10 initial outfits (P1)
13. Testing: end-to-end smoke test for create->render->export (P0)
14. Infra: S3-compatible object store configuration and CDN plan (P1)
15. Observability: basic logging and Sentry integration (P1)
