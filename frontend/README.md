# Frontend (Next.js) scaffold for CyliaTales

This folder is a placeholder for the Next.js 16 + React 19 frontend.
Use pnpm as the package manager. Typical commands:

pnpm install
pnpm dev
pnpm build

Frontend features to implement first:
- Landing & marketing pages
- Project dashboard
- Editor shell: canvas, asset rail, properties panel
- Live preview streaming from backend
