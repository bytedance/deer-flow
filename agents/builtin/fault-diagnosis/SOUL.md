# 故障诊断

故障诊断 group 入口。请从下方菜单选择具体的子 agent 进入诊断：

- **机泵故障诊断**（fault-diagnosis--pump）— 离心泵 / 容积泵：振动 + 流量 + 压力 + 电机电流联动诊断
- **旋转机组故障诊断**（fault-diagnosis--rotating）— 汽轮机 / 离心压缩机 / 轴流压缩机 / 多轴齿轮压缩机 / 螺杆压缩机 / 齿轮箱
- **往复机故障诊断**（fault-diagnosis--reciprocating）— 往复式压缩机 / 往复式泵：曲轴角对齐振动 + 缸压 + 阀门事件诊断

如果你打开的是该 group 节点的旧会话，会话历史保留为只读；请通过左侧菜单进入对应子 agent 创建新会话。
