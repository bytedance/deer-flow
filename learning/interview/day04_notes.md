## 题意与练习文件

题目：[LeetCode 49 官方题面](https://leetcode.com/problems/group-anagrams/description/)  
练习：[day04_group_anagrams.py](day04_group_anagrams.py)

给定字符串列表，把互为字母异位词的字符串分到同一组，返回所有组。分组及组内顺序不限，原字符串与重复次数须保留。

```python
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

# 一种合法结果：
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

题目边界：1～10000 个字符串，每个长度为 0～100，仅含小写英文字母。空字符串是合法输入，例如 `[""]` 应分为 `[[""]]`。

## 当前思路问题

沿用 D02 的字符频次经验。若用一个字典收集分组，value 放同组的字符串列表，那么 key 应该表示单词的什么特征，才能让 `eat`、`tea`、`ate` 对应到同一组？

学习者回答：“字母以及字母出现的次数”。分组特征正确；尚未独立给出 Python 可用的键表示或完整正确性解释。

本次讲解：题目只有 26 个小写英文字母，可用固定顺序 a～z 的 26 个位置存频次。每个单词新建 `counts = [0] * 26`；字符下标为 `ord(ch) - ord("a")`，对应位置计数加一。字典和列表不能直接作为字典键；这里由整数构成的 `tuple(counts)` 可以作为键，且固定位置顺序不受单词中字母顺序影响。上述实现方式由助手提示，不记为学习者独立推导。

时间复杂度已回答：学习者给出 `O(n*k)`，说明“每个字符串以及每一字母都要遍历”。常规分析下回答与理由正确。助手补充：26 位计数初始化、元组构造和键的哈希都是固定开销，字典查找按平均情况分析。严格计入空字符串等情况时，可写为 O(S+26n)，S 为全部字符串的字符总数；常见的 O(nk) 表述默认长度尺度至少按 1 计，不因该边界否定学习者正确的主循环分析。

额外空间已回答：学习者给出 `O(n)`，理由为“一共 n 个字符串，每个字符串都要存到字典中”，结论与线性增长判断正确。助手补充：设分组数为 g，字典键共 O(26g)，组内列表总共保存 n 个原字符串的引用，返回的外层列表有 g 个引用，临时 counts 为 26 位。该 Python 实现不复制输入字符串内容，额外空间为 O(n+26g)，g≤n 且字母表固定，因此为 O(n)。这不是把输入字符串本身的字符存储重新计入额外空间。
