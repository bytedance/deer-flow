## 题目范围

已于2026-09-21核对 [LeetCode 官方题面](https://leetcode.com/problems/merge-intervals/description/)：每个输入项为 [start,end]，合并所有重叠区间，返回覆盖全部原范围且互不重叠的区间列表。端点相等也视为重叠，输入不保证有序。

- 区间数为1至10000，每个区间恰有两个端点。
- 端点满足 0 <= start <= end <= 10000，允许单点区间。
- 返回区间列表，不是区间数量或覆盖长度。

手算题 [[8,10],[1,4],[3,7],[10,12]]，学习者正确回答 [[1,7],[8,12]]。排序依据选择左端点，但明确不知道原因；助手解释起点单调时，已经分开的较早合并段不可能再被后续区间连接，因此只需与结果最后一段比较。对包含情况 [1,10] 与 [3,5]，学习者正确回答 [1,10]，助手补充右端点取 max 的理由。

编码提示已提供：intervals.sort(key=lambda item: item[0]) 的含义，以及空结果先加入、后续区间与结果最后一段比较、重叠更新末端/不重叠追加、最后返回的步骤；没有代写完整循环。学习者实际首版采用 i 与 i+1 配对、合并后 i+=2 的实现，尚未保持结果最后一段可继续合并的状态。
