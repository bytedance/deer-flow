## 结果构造的效率讲解

学习者对前导零解释表示明白并要求继续。助手核对最新文件仍使用 `result = str(now) + result`，没有再次运行未改动的解法。

本次讲解：令 N 为两个输入长度的较大值，最多处理 N+1 位；每次头部拼接要构造新字符串并复制已有结果，累计工作量为 1+2+…+N，当前实现时间 O(N²)。用列表按低位到高位追加字符串数字，最后反转并 join，可将结果构造降为 O(N)。解释 `append`、原地 `reverse`（返回 None）与字符串 `join`，由学习者自行修改初始化、收集当前位、最终返回三个位置；尚未收到优化后的代码，也未验收复杂度独立回答。

## 复杂度回答与首次练习收尾

学习者回答：时间 O(max(m,n))，“只遍历了一遍两个字符串”；空间 O(2*max(m,n))，“中间 result 和最后 text 都要算”。

时间表达正确，助手补充：反转与 join 也各自需要线性时间，这些步骤顺序执行，累加后仍为 O(max(m,n))。空间已正确识别为线性增长，O(2N) 与 O(N) 同阶，规范写法省略常数 2。若讨论包含返回结果的总空间，result 和 text 均占线性空间；若按额外空间不计返回值的口径，result 列表本身仍为 O(N)。空间判断不记为错误，但化简规则、输出空间口径与完整理由尚待独立复述。
