# DeerFlow 财报研读与对比助手

> 个人项目展示草案，2026-09-18。按学习者要求采用金融方向；当前为学习与开发阶段，尚未发布到个人 GitHub 仓库。财报功能待开发，现有成果限于下方“当前功能”。

基于 [DeerFlow](https://github.com/bytedance/deer-flow) 的个人二次开发项目。目标是读取公开财报，查询营业收入、归母净利润和经营活动现金流量净额，核对单位与口径，生成带出处的年度对比报告。仓库名候选：`deerflow-financial-research`。详细范围见 企业与个人项目分配（旧学习计划已删除）。

第一版使用 1 家公司、2 个完整年度的文本/Markdown 财报材料，保留原始报告链接与页码/章节。公开披露材料可来自上市公司官网或监管披露平台，例如 [SEC EDGAR](https://www.sec.gov/search-filings)；具体样例后续选定，公开仓库优先提供合成测试材料与来源清单。模型负责检索与解释，数值计算由工具完成。

## 当前功能

- 新增 `count_file_lines` 工具，通过项目已有的文件读取能力获取文本，使用 `splitlines()` 统计行数。
- 在本地配置中注册工具，验证 Agent 可以调用它。
- 空文件返回 `0`；文件不存在时保留读取异常，由已有工具异常处理中间件处理。
- 编写普通文本、空文本与缺失文件三个测试，并在普通文本测试中检查读取函数的调用次数和参数。

本地 `config.yaml` 中的注册片段如下，位于现有 `tools:` 列表下：

```yaml
- name: count_file_lines
  group: file:read
  use: deerflow.tools.file_stats:count_file_lines
```

真实配置和 API 密钥不属于公开项目文件。发布时提供无密钥的配置示例与虚构样例数据。

## 已有验证与限制

- 2026-09-17：通过实际网页调用，普通文件返回 `3`；缺失文件返回错误工具消息，Agent 能继续回复。
- 2026-09-18：Windows 本机运行三个 pytest 用例，结果为 `3 passed`；VS Code 测试按钮也已运行通过。
- 这些单元测试模拟文件读取，验证计数、异常传播及参数传递；它们不能证明真实 Sandbox 读取或多用户隔离正确。
