## ADDED Requirements

### Requirement: Basic presentation — line/bar/table charts + cards
At Basic tier, the system SHALL render results using ECharts line/bar charts, data tables, and KPI cards as defined in the current agent SOUL.md.

### Requirement: Pro presentation — enhanced charts with annotations
At Pro tier, the system SHALL render enhanced charts: confidence bands on forecasts, vertical markers for change points and anomalies, and model comparison overlays.

#### Scenario: Forecast with confidence band
- **WHEN** Pro trend analysis completes with multi-model output
- **THEN** the ECharts SHALL overlay all fitted model curves and annotate the selected best model

#### Scenario: Anomaly cluster timeline
- **WHEN** Pro anomaly detection returns anomaly clusters
- **THEN** the system SHALL render a cluster summary table with time spans and dominant metrics

### Requirement: Ultra presentation — panoramic dashboard + NL interpretation
At Ultra tier, the system SHALL render a comprehensive dashboard with multiple coordinated views and SHALL include a natural language interpretation of the key findings generated by the agent's LLM.

#### Scenario: Panoramic monitoring dashboard
- **WHEN** Ultra analysis completes for 3+ equipment
- **THEN** the system SHALL render a dashboard with risk matrix, health score gauge, top anomalies table, and trend sparklines

#### Scenario: NL interpretation of findings
- **WHEN** Ultra analysis finds critical anomalies
- **THEN** the agent SHALL generate a natural language paragraph summarizing: "监测周期内发现 3 项关键异常，其中 {设备名} 的振动烈度超标最为严重（偏差 +45%），可能指示轴承早期磨损。建议安排停机检查。"
