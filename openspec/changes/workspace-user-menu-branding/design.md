## Context

`WorkspaceNavMenu` 同时承担侧边栏底部用户身份展示和用户菜单入口。当前菜单包含：

- 设置
- 关于本系统

“关于”内容本身已经存在于设置弹窗内部的“关于”分区中，因此用户菜单里的单独“关于本系统”入口是重复入口。

公司名称文案分布在关于页、落地页 footer、隐私政策和服务条款中，应统一替换，避免同一产品内运营主体不一致。

## Decision

### 1. 用户菜单只保留设置入口

删除 `WorkspaceNavMenu` 用户下拉菜单中的“关于本系统”菜单项和分隔线，仅保留打开设置弹窗的菜单项。

设置弹窗内部的“关于”分区不调整。用户仍可从设置弹窗内访问关于内容。

### 2. 公司名称全量替换

将前端源码中的旧公司名称替换为“深圳因思科技有限公司”。本次不修改邮箱、产品名、登录背景或其它品牌视觉元素。

## Non-Goals

- 不修改 Next.js 配置、依赖或启动方式
- 不移除设置弹窗内部的“关于”页面
- 不调整侧边栏品牌标题和图标，该部分由 `workspace-brand-ai-title` change 覆盖
