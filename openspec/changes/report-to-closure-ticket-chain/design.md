## Context

闭环工单是 DeerFlow 主流程的收口环节。当前报告和诊断的结论无法直接转化为工单，导致用户需要通过外部渠道手动创建，链路不可追踪。

## Goals / Non-Goals

**Goals:**
- 从报告/诊断结果一键创建工单，携带来源上下文
- 工单可回溯到触发源
- 工单状态流转保留来源和处理责任信息

**Non-Goals:**
- 不做工单系统本身的重大功能扩展
- 不覆盖工单的审批和分配流程

## Decisions

### 决策 1：工单携带不可变的 source 引用

- **选择**：工单创建时记录 `source: { type: "report"|"diagnosis", id, runId, contextSnapshot }`
- **理由**：不可变的 source 引用确保即使原报告被删除或更新，工单仍可回溯

### 决策 2：双向链接而非单向

- **选择**：工单创建后，在源报告/诊断页也展示关联的工单列表
- **理由**：双向链接让用户从两个方向都能追踪完整链路

## Risks / Trade-offs

- [风险] 报告被删除后工单 source 指向无效 → 保留 source 快照而非实时引用
