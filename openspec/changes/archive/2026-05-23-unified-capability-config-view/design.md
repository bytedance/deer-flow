## Context

基于 ISSUE-09 的统一配置模型，交付一期统一能力配置视图。目标不是一次性完成所有高级操作（如创建、编辑、审批），而是先统一"看"的体验。

## Goals / Non-Goals

**Goals:**
- 统一列表视图：按类型 tab 或 filter 查看所有能力
- 详情视图：查看能力详情、作用域、最近变更
- 术语与 ISSUE-09 保持一致

**Non-Goals:**
- 不实现能力创建/编辑/删除（二期）
- 不实现审批工作流
- 不实现批量操作

## Decisions

### 决策 1：一期只做查看，不做编辑

- **选择**：统一视图一期仅支持查看（list + detail），编辑沿用现有各模块的独立入口
- **理由**：先统一认知，编辑操作可以在后续逐步迁移到统一入口

### 决策 2：视图按类型 tab 组织

- **选择**：左侧或顶部按 Model / Skill / MCP / Connector / Agent 分类 tab
- **替代方案**：单一列表混合所有类型 → 配置者难以定位

## Risks / Trade-offs

- [风险] 只读视图可能被感知为"不完整" → 明确标注一期范围和后续计划
