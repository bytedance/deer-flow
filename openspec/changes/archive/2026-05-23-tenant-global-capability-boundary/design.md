## Context

在 ISSUE-09 定义了 scope 枚举（GLOBAL / TENANT / TENANT_OVERRIDE）后，需要实现具体的边界逻辑：继承链、覆盖规则、影响分析和审计。

## Goals / Non-Goals

**Goals:**
- 定义全局能力的继承和租户覆盖规则
- 变更时能解释和追踪影响范围
- 关键变更具备审计记录
- 至少一条租户启用能力的验证路径

**Non-Goals:**
- 不实现完整的审批工作流（二期）
- 不覆盖行业层的特殊边界规则（由 ISSUE-13 覆盖）

## Decisions

### 决策 1：TENANT_OVERRIDE 采用继承+覆盖模型

- **选择**：租户启用能力时默认继承全局配置，TENANT_OVERRIDE 能力显式覆盖指定字段
- **替代方案**：租户独立复制全局配置 → 全局更新后租户不同步
- **理由**：继承模型确保全局安全策略升级时租户自动受益

### 决策 2：停用影响分析必须先于执行

- **选择**：停用一个能力前，系统必须计算并展示受影响租户列表
- **理由**：全局能力停用可能影响大量租户，必须有预检查和确认

## Risks / Trade-offs

- [风险] 继承链复杂时性能问题 → 缓存继承解析结果
