## ADDED Requirements

### Requirement: Primary entry points are classified
The system SHALL have a documented classification of workspace top-level navigation items into primary entry points and extension domains.

#### Scenario: Navigation taxonomy is clear
- **WHEN** a product manager reviews the workspace navigation structure
- **THEN** each top-level navigation item is labeled as either "primary entry point" or "extension domain"

#### Scenario: Taxonomy is approved by product owner
- **WHEN** the navigation taxonomy is presented for approval
- **THEN** the workspace product owner signs off on the classification

### Requirement: Extension domain boundaries are defined
The system SHALL define what qualifies a page or feature area as an extension domain versus a primary entry point, with criteria that can be applied to future additions.

#### Scenario: New feature can be classified
- **WHEN** a new feature or page is proposed for the workspace
- **THEN** the team can apply the classification criteria to determine whether it belongs as a primary entry or extension domain
