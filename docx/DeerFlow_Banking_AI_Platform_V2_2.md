## 一、执行摘要

### 1.1 DeerFlow 是什么

**DeerFlow 2.0** — 字节跳动官方主推的超级企业 Harness Agent 框架

DeerFlow 是当下 AI 智能体领域**最成熟、热度最高**的开源工具，为 AI 智能体提供**安全、可控、稳定**的运行环境，解决传统智能体运行卡顿、易出错、不安全、难落地的核心痛点。

**核心优势：**

| 优势 | 说明 |
|------|------|
| **超级企业 Harness Agent 底座** | 量产级实用性，企业级稳定运行 |
| **统一编排** | 一个入口调度 RAG、数据分析、外部系统 |
| **Skill 可复用** | 业务能力封装为独立模块，按需组合 |
| **多 Agent 协作** | Lead Agent + Subagent 并行执行，复杂任务自动拆解 |
| **企业级 Governance** | 权限控制、审计日志、Eval 评测全链路覆盖 |

### 1.2 一句话方案

**基于 DeerFlow Harness Engineering，构建 AI 办公助手，RAG 知识问答为核心，智能数据分析为辅助。**

### 1.3 核心价值主张

```
AI 让流程「变短 · 变快 · 变自动 · 变规模化」

变短   ── 人工步骤减少 80%（从 5 步 → 1 步）
变快   ── 响应速度提升 100x+（从小时/天 → 秒级）
变自动 ── 人工介入降低 85%（从 100% → 仅异常复核）
变规模 ── 单实例 50 并发 → 集群 500+ 并发
```

### 1.4 两大能力定位

| 能力 | 在框架中的角色 | 核心价值 |
|------|--------------|---------|
| **RAG 知识库** | Skill: `banking-rag` | 精准问答，减少人工查阅 |
| **数据分析** | Skill: `banking-analytics` | OLAP 多维度分析，释放分析师 |

> **关键设计**：两个能力不是两个独立系统，而是同一个 Agent 框架下的两个 Skill，业务人员按需调用。

## 三、核心能力：Harness Engineering

### 3.1 什么是 Harness Engineering？

**Harness = 驾驭系统，让开发人员聚焦业务而非底层**

```
传统开发模式：
  写代码 → 调 API → 处理异常 → 维护迭代 → 新场景重新写

Harness Engineering 模式：
  选 Skill（业务能力包）→ 配置 MCP（外部连接）→ 组合流程 → 上线
```

| 状态 | 说明 | 可视化 |
|------|------|-------|

# 银行 RAG 技能

## 能力矩阵

| 能力 | 说明 | 调用方式 |
|------|------|---------|
| 语义检索 | 理解金融术语，精准匹配 | `dify_rag_search()` |
| 混合检索 | 向量 + 关键词双重召回 | `dify_hybrid_search()` |

| 多文档综合 | 跨文档整合信息 | `llm.synthesize()` |

## 检索流程

1. **Query Rewrite**
   - 同义词扩展
   - 金融术语规范化
   - 用户意图澄清（如需要）

2. **检索阶段（Dify RAG Pipeline）**
   - 向量相似度检索（Top-K）

3. **重排序**
   - Cross-Encoder 重排序
   - 相关性阈值过滤

4. **答案生成**
   - 上下文组装
   - LLM 生成答案
   - 来源标注
