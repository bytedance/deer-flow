# ai-report DuckDB V2 Design Docs

This directory contains the DuckDB V2 design for the future `ai-report` skill.

Recommended reading order:

1. `01-overview-and-modes.md` — product goal, Design Mode, Runtime Mode, unified pipeline.
2. `02-duckdb-schema.md` — long-lived definition database and per-run database schemas.
3. `03-run-report-data-flow.md` — where runtime data comes from and where it is written.
4. `04-report-design-md.md` — final report design Markdown export and checkpoint write-back rules.
5. `05-implementation-phases.md` — phased implementation plan.

`ai-report-duckdb-v2-design.md` remains the canonical full design until implementation stabilizes.
