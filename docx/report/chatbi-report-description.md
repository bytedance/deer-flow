# 智能报告生成 报表生成模块

由 Agent 智能体驱动的智能报表工厂——分析师"说一句话"，问数智能体通过 MCP 调用 智能报告生成 Skill，自动完成从数据查询到正式报告生成的全流程。

---

## 它解决什么问题

金融机构每月、每季都要生成大量固定格式的分析报告——月报、季报、专题分析。传统方式依赖分析师手工查数、填表、写解读、排版，重复劳动多、格式不统一、耗时长。一个含 20 个指标的专题报告，分析师手工完成通常需要半天；而本模块可在分钟级完成初稿生成。

本模块将这一流程自动化：**分析师只需上传一份预定义格式的 Markdown 模板（模板中标注好要什么数、用什么口径），问数智能体自动完成数据查询、计算、解读、图表生成、排版，直接输出可分发的正式报告。**

---

## 核心组件与角色

| 组件 | 角色 |
|---|---|
| **Agent 智能体（问数智能体）** | 全流程总指挥，负责任务编排、决策判断、人机交互 |
| **智能报告生成 Skill** | 报表生成的技能引擎，封装九步流水线逻辑 |
| **MCP（模型上下文协议）** | Agent 与智能问数数据源之间的桥梁，负责查询指标数据 |
| **智能格式校验** | 上传模板时的自动检查，确保指标编号、计算声明合规 |
| **图表引擎** | 根据数据特征自动生成柱状图、折线图等，嵌入报告中 |
| **渲染引擎** | 将数据填充进模板，输出 Markdown 和 Word 格式 |

## 核心工作原理

问数智能体作为"总指挥"，通过 MCP 协议调用 智能报告生成 Skill，串联七个能力模块完成全流程：

### 第一步：模板上传与智能格式校验

分析师上传 Markdown 模板后，问数智能体首先调用 Skill 中的智能格式校验模块——检查指标编号是否合法、计算声明是否合规、描述要求是否完整、图表定义是否规范。校验结果由分析师确认，发现问题可及时修正模板后再继续，而非等到出报告才发现数据填错了地方。

### 第二步：MCP 取数

问数智能体通过 MCP 协议向智能问数数据源发起查询请求，并行查询多个指标数据。系统支持两种运行模式：

- **模拟模式**：使用预设的演示数据，无需连接真实数据源，适合演示和测试
- **真实模式**：通过 MCP 连接智能问数引擎查询实际数据，适合正式业务使用

查数结果自动进行单位换算（万元、百分比、千分比等），拼装成结构化的宽表数据，为后续计算、解读、图表生成提供统一的数据基础。

### 第三步：衍生指标计算

分析师可以在模板中声明"计算列"，例如"同比增长率"、"占比"等。问数智能体调用大语言模型，根据计算规则自动生成 Python 计算代码，并执行计算出结果后填入报表。这一步解决了手工算指标容易出错、公式不统一的问题。

### 第四步：AI 辅助解读

问数智能体调用大语言模型，基于宽表数据自动生成指标的自然语言解读——例如"王益联社贷款余额 8.5 亿元，位居铜川市首位，较市平均高出 25%"。分析师无需逐条撰写，直接复用 AI 生成的解读文字。

### 第五步：图表定义与渲染

分析师可在模板中声明图表类型（柱状图、折线图、饼图等）及展示维度（时间趋势、机构对比、占比分布）。问数智能体根据宽表数据和图表定义，自动调用图表渲染引擎生成对应图表，嵌入 Markdown 和 Word 报告中。常见图表类型对应关系：

- **时间序列数据**（多年/多月）→ 折线图，展示趋势变化
- **机构对比数据** → 柱状图，展示横向排名
- **占比数据**（百分比）→ 饼图，展示构成结构

### 第六步：渲染输出

问数智能体调用渲染引擎，将填充好的数据、图表、解读渲染为两种格式：

- **Markdown 报告**：便于在聊天界面中直接查看和分享，含数据表格和嵌入式图表
- **Word 报告**：包含完整排版格式，可直接用于正式分发

## 风控审核设计

系统在三个关键节点引入风控审核，而非全流程"一键自动化"：

- **格式审核**：模板指标编号、计算声明、图表定义是否合规，分析师确认后再继续
- **数据审核**：查询结果出来后，分析师判断数据是否合理、是否需要调整口径
- **解读审核**：AI 生成的文字解读和图表，分析师确认是否准确、是否需要调整

这样做的好处是：**分析师始终掌控流程，问数智能体承担重复劳动，风控审核确保错误可及时在流程中发现而非等到报告发出才发现。** 对于复杂报表，分析师可以多次介入调整；对于简单报表，也可以一路"审核通过"快速出结果。

## 关键优势

| 优势 | 说明 |
|---|---|
| **说一句话就跑完** | 分析师只需说"生成报表"，其余全部由问数智能体自动串联 |
| **MCP 标准化取数** | 通过 MCP 协议与智能问数数据源交互，取数方式标准化、可扩展 |
| **Skill 封装可复用** | 智能报告生成 Skill 封装完整流水线逻辑，可在不同场景中复用 |
| **容错不中断** | 查数失败、计算失败、解读失败时自动标注，不影响其他部分正常输出 |
| **图表自动生成** | 根据数据特征自动匹配图表类型，无需手工绘图 |
| **双格式输出** | 同时生成聊天内嵌版和正式分发版 |
| **模板可复用** | 一套模板多次使用，只需替换数据口径即可 |
| **演示便捷** | 内置模拟数据模式，无需接入真实数据源即可完整演示 |
| **可审计可追溯** | 每一步中间结果文件完整留存，失败项明确标注 |
