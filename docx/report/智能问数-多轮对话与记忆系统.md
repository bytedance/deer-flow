# 智能问数 · 多轮对话与记忆系统

**一句话定位**：Agent 智能体的记忆中枢——多轮对话上下文保持、主动澄清、长期记忆，支撑复杂业务场景下"说得清、记得住、随时续"的交互体验。

---

## 它解决什么问题

传统对话 AI 只能"问一句答一句"——上下文窗口一满就丢记忆，用户换个说法重复背景模型就不认了，流程中断后无法续接。

在金融机构真实业务中，报表生成往往是跨分钟甚至跨小时的长程任务：

- 分析师说"我想看王益联社的"→ 系统追问"要哪个时间段的？"→ 分析师回答"2025年"→ 系统继续查数——这是多轮澄清
- 上次领导说"描述风格要简洁、口径用万元"→ 下次新对话里分析师无需重复——这是跨会话记忆
- 中午跑了一半的报表生成，下午回来直接续上——这是会话可恢复

本模块正是为这些场景设计的：**让 Agent 真正理解上下文、记住用户偏好、随时能续上一步。**

---

## 核心组件与角色

| 组件 | 角色 |
|---|---|
| **Agent 智能体（问数智能体）** | 全流程总指挥，理解上下文、管理对话状态 |
| **Thread 会话管理** | 每个对话线程独立存储消息历史，支持跨轮次上下文复用 |
| **中间件链** | 在 Agent 核心外串联记忆注入、上下文压缩、澄清拦截等横切能力 |
| **记忆更新队列** | 对话结束后异步更新记忆，支持防抖合并，不阻塞主对话流程 |
| **记忆存储（三层）** | 短期（消息流）+ 中期（per-thread 文件系统）+ 长期（per-user memory.json） |
| **检查点持久化** | 会话状态可快照可恢复，支持断点续接 |

---

## 核心工作原理

### 多轮对话：上下文保持与主动澄清

**上下文保持**：每次用户发送消息，Agent 会自动加载同一 Thread 内之前的消息历史，无需用户重复说明背景。对话轮次越多，Agent 对上下文理解越精准。

**协议级澄清**：当用户表达模糊或缺少必要信息时，Agent 不是"猜一个最可能的答案跑下去"，而是主动停下来问清楚。例如用户说"查一下贷款余额"，Agent 会追问"要查哪个时间点/哪家机构？"——这就是协议级澄清中断，不是用户在 UI 上手动点取消，而是被做成协议级中断：Agent 调用澄清工具 → 中间件拦截 → 返回终止信号 → 前端展示澄清卡片 → 用户回答后复用同一会话 ID 续答。

**检查点持久化**：每次 Agent 执行前后都会将会话状态写入检查点——消息列表、已调用的工具、中间产物全部可快照。中途断电或用户关闭页面，下次进入同一 Thread 时自动恢复状态，任务可续接。

### 记忆系统：三层记忆正交设计

系统把"刚才说的 / 这次会话留下的 / 跨会话一直记得的"切成三层，各有存储、各有生命周期，互不污染：

**短期记忆（工作记忆）**：当前对话的消息流，按轮次实时追加存在会话状态里。当 token 数接近模型上限时，上下文压缩中间件自动触发，将消息流压缩成摘要存入摘要通道，释放上下文窗口。这是"刚才说的"那层。

**中期记忆（per-thread 文件系统）**：每个会话独立挂载 workspace / uploads / outputs 虚拟目录，文件级隔离，生命周期与会话绑定。例如报表生成过程中产生的中间文件、解析后的 parsed.json、宽表 JSON，都存在这里，下次续跑时工具能读到。这是"这次会话留下的"那层。

**长期记忆（跨会话记忆）**：按用户、按 Agent 维度落盘的 memory.json，包含用户的工作上下文、个人偏好、历史事实。例如"某领导偏好简洁描述风格"、"某部门常用口径是万元"——这些跨会话一直要记的信息，新对话开始前自动注入 Agent 系统提示词。这是"跨会话一直记得的"那层。

### 记忆更新流程

对话结束后，记忆中间件将对话消息加入更新队列（不是立刻写盘，而是等待 30 秒防抖——把短时间内的多轮对话合并），然后交给 LLM 摘要合并后写入 memory.json。系统还会检测两类信号：

- **纠正信号**：用户指出"上次那个不对"——LLM 摘要时优先淘汰被纠正的事实
- **强化信号**：用户明确"这个偏好记住"——LLM 摘要时优先固化该偏好

这让记忆有"权重"，不是把所有对话一视同仁写入。

---

## 人机协同设计

系统在两个关键节点引入人工干预：

- **澄清中断**：用户表达模糊时，Agent 主动停下，等待用户补充信息后再继续，而非猜答案跑下去
- **记忆修正**：用户可随时查看、编辑、清除自己的 memory.json，记忆不完全由系统自动生成

---

## 关键优势

| 优势 | 说明 |
|---|---|
| **说得清** | 主动澄清机制让模糊需求被问清楚再跑，而不是猜答案 |
| **记得住** | 三层记忆让上下文、历史偏好、中间产物各归其位，不丢信息 |
| **随时续** | 检查点持久化让长程任务可恢复，中断后回来接着跑 |
| **个性化为王** | 跨会话记忆让用户偏好跨对话复用，无需重复告知 |
| **记忆有权重** | 纠正和强化信号让记忆动态优化，被纠正的事实自动淘汰 |
| **多用户严格隔离** | user_id 三层解析 + 文件路径物理隔离，A部门和B部门数据不串 |
