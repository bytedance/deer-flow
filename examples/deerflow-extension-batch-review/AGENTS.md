# Batch review extension

Use only public deerflow_extension_api contracts. The host supplies a lazy
request-bound read capability, never a global reader or caller-controlled owner.
Do not import app/deerflow internals or copy native storage models into this
package. No new provider request, database, worker or write action belongs here.

Browser assets are manifest-listed native modules. Preserve literal report/source
text through textContent/DOM text nodes, never raw innerHTML. Only supported
native citation destinations get buttons; code stays literal and unknown IDs
remain unavailable. Selection and account/thread changes invalidate the entire
report/evidence view; cancel in-flight requests and suppress late responses.

Keep execution completion separate from stored acceptance. Default/custom-agent
actions use host-owned registered-page navigation; page context is not authority.
Return through openConversation for native retries and controls. Real browser
checks must cover the actual action/sidebar entry and asset manifest, not only
an isolated DOM rendering helper. Test fixture authentication is synthetic and
loopback-only; it must never become a deployed Gateway configuration.
