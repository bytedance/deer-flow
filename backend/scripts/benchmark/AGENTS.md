### Backend Benchmarks

Keep `scripts/benchmark/` standalone and reproducible. Import production
functions and reuse their runtime.

- `context_snapshot` needs provider env vars for `run-live`. See its README.
  `summarize` and pytest run offline.
- `context_memory_comparison` runs Gateway offline with SQLite. Report
  original- and fresh-thread results separately.
- Sandbox benchmarks use the production lifecycle. Reject negative or NaN
  timing values before provider creation, export no secrets, and fail on
  cleanup errors. See the sandbox benchmark README for options and tests.
- Pin datasets by immutable revision and SHA-256. Require a caller-provided
  local path without automatic downloads. Label synthetic cases. Manifests
  may include stable IDs and source locators.
- Read provider credentials and endpoints from named env vars. Version model
  IDs, inference parameters, prompts, retries, clocks, and seeds in eval config.
- Public raw results may include case IDs, policy decisions, model hypotheses,
  grades, and non-secret response metadata. Keep dataset text, reference
  answers, memory, and full provider payloads in ignored local run directories.
  Exclude credentials and response headers from commits.
- Use fixed clocks and deterministic offline ordering. Record config, manifest,
  prompt, dataset, and git revisions in results.

`scripts/benchmark/deermem_eviction/` evaluates the production
`select_facts_for_capacity()` implementation used by DeerMem. It compares only
the historical `confidence` policy and PR #4789's opt-in `hybrid-v1`; do not add
another eviction strategy to this evaluation. Run its offline checks from
`backend/`:

```bash
PYTHONPATH=. uv run python -m scripts.benchmark.deermem_eviction validate-contracts
PYTHONPATH=. uv run python -m scripts.benchmark.deermem_eviction validate --dataset "$LONGMEMEVAL_ORACLE_PATH"
PYTHONPATH=. uv run python -m scripts.benchmark.deermem_eviction run-policy \
  --dataset "$LONGMEMEVAL_ORACLE_PATH" \
  --output-dir /tmp/deermem-eviction-policy-run
PYTHONPATH=. uv run pytest tests/test_bench_deermem_eviction_*.py -q
```

The offline test suite must not require network access, provider credentials,
or the LongMemEval dataset. Small LongMemEval-shaped fixtures must be synthetic
and generated by tests.

`scripts/benchmark/concurrency/` compares SQLite and Postgres contention on
`users` with separate OS processes. `worker.py` connects via SQLAlchemy with
the app's SQLite PRAGMAs after the orchestrator runs Alembic once.
`run_concurrency_bench.py` uses a disposable schema outside `public` in the
throwaway database supplied via `--pg-url`. It starts timing after a READY/GO
barrier and fails on a crash, short op count, or any errors. Run from `backend/`.

```bash
uv run python scripts/benchmark/concurrency/run_concurrency_bench.py \
  --backend sqlite --workers 2,4,8,16 --ops-per-worker 50 --read-ratio 0.7
uv run pytest tests/test_bench_concurrency.py tests/test_bench_worker.py -q
```
