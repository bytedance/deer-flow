# SLA 与工单升级策略

设备运维工单按严重程度划分四级,对应不同的响应与恢复时长指标。

<!-- anchor: p1 -->
## P1 紧急工单

定义:产线整线停机,或安全风险(燃爆、泄漏、人身)。

- **MTTR 上限**:4 小时。超时即触发 SLA 违约告警
- **响应**:5 分钟内必须有现场工程师确认接单
- **升级**:超时未恢复自动 page 值班主管 + 设备经理,并开启战情室频道
- **关闭条件**:产线连续运行 ≥ 30 分钟无异常,完成根因分析草稿

<!-- anchor: p2 -->
## P2 重要工单

定义:单台关键设备停机但不影响整线节拍,或备件已耗尽。

- MTTR 上限:24 小时
- 响应:30 分钟内接单
- 升级:超 12 小时未结案抄送车间主任

<!-- anchor: escalation -->
## 升级路径

所有工单的人员升级链:**值班工程师 → 班长 → 设备经理 → 厂长**。每一级的等待时间在工单表《escalation_policy》字段中按数据库枚举存储,超时由调度服务自动推进,无需手工干预。
