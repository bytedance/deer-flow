# 季度点检计划

季度点检覆盖年度大修之外的中等深度检查,通常停机半天以内即可完成。

<!-- anchor: quarterly_checklist -->
## 季度检查清单

每季度第一个完整周末执行:

1. 主电机绝缘电阻测试(摇表 1000 V),应 ≥ 100 MΩ
2. 联轴器对中复测,径向偏差 ≤ 0.05 mm,角度偏差 ≤ 0.03 mm/m
3. 急停按钮回路测试 —— 每个回路逐一按下并确认主接触器跳开
4. 备品备件盘点,核对 ERP 库存与实物
5. 安全阀起跳压力校验(由特种设备检测机构执行,留校验报告)

## 热成像计划

热成像由可靠性团队按年度计划安排,夏季(7–8月)、冬季(12月)各一次,覆盖电气柜、母线、变压器低压侧、变频器进出风口。
