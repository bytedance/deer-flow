# 安全协议

设备运行期间的人身安全要求,所有现场人员必须遵守。

<!-- anchor: estop_test -->
## 急停测试

每月第一个工作日,班组长组织急停测试。流程:

1. 通知中控室进入维护模式,关闭自动化运行
2. 依次按下产线上每个急停按钮(含拉绳开关)
3. 在 PLC 监控画面确认对应区域的主接触器跳开,主电机零速
4. 测试完毕后复位,运行无负载试机 5 分钟
5. 把测试记录(含每个急停的"按下→断电时间")存入安全档案柜

## 上锁挂牌(LOTO)

任何动力源相关检修必须执行 LOTO:断开总闸 → 上专用锁 → 挂个人姓名牌 → 用万用表验电。多人作业需多锁多牌,任何一把锁不开,设备不能复电。

## 个人防护装备

进入车间必须佩戴安全帽、防护眼镜、防砸鞋;靠近高温介质额外戴防烫手套;焊接、切割作业按热工作业票要求穿阻燃服。
