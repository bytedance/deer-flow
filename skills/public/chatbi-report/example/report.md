# 王益联社 2026 年 3 月经营分析报告 — 双轴配色定制

## 一、行社风险与规模分析

### 1.1 贷款余额、存款净增与不良率综合分析

2025年，从规模指标看，王益联社贷款余额8.50亿元、存款日均净增1250.50万元，均位居铜川市首位，印台联社（7.23亿元、980.20万元）和耀州联社（6.81亿元、850.75万元）分列其后，宜君联社规模最小（4.57亿元、420.30万元）；从风险指标看，不良率由低到高依次为王益联社（0.0235%）、印台联社（0.0280%）、市平均（0.0290%）、耀州联社（0.0310%）、宜君联社（0.0345%），与贷款余额排序呈反向关系，即规模越大的行社不良率越低；占比方面，王益联社（31.35%）在铜川市六家行社中占比最高，与其贷款规模领先的优势一致。横向比较，王益联社不良率（0.0235%）优于市平均（0.0290%），但省平均不良率（0.0185%）更低，表明铜川市整体风险管控水平仍有提升空间。
